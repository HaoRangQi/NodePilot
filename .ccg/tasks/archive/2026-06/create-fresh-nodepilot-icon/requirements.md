# Create Fresh NodePilot Icon

## User Request

Create a suitable new icon from scratch, without looking at or deriving from the current icon files.

## Scope

- Replace the project brand SVG with a new original vector icon.
- Export the icon to the Tauri bundle icon set.
- Refresh the README preview image from the same source.
- Keep the implementation independent from any previous icon artwork.

## Design Direction

- macOS-style rounded-square application icon.
- Pale mint base aligned with the unified UI direction.
- Compass/navigation pointer to communicate "Pilot".
- Connected version nodes to communicate Node runtime/version management.
- No text, so the icon remains readable at small sizes.
